# Changelog

All notable changes to `typescript-skills` are documented here. Versioning follows [SemVer](https://semver.org/).

## 1.0.0

### Added
- Initial release. The `typescript-expert` skill, extracted from `frontend-skills` 1.0.0 so it can be
  installed without React/Next.js.
- Ships the skill's references (strict `tsconfig` baseline, cheatsheet, utility types) and
  `scripts/ts_diagnostic.py`.

### Migration
- The skill's address changed from `frontend-skills:typescript-expert` to
  `typescript-skills:typescript-expert`.
